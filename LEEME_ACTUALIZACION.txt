ERROR CORREGIDO
ModuleNotFoundError: No module named 'psycopg'

SQLAlchemy 2.1 utiliza Psycopg 3 como controlador predeterminado para PostgreSQL.
La regla SQLAlchemy>=2.0,<3 permitía instalar esa versión en un nuevo despliegue,
pero requirements.txt solo incluía psycopg2-binary, que instala un módulo distinto.
Ahora requirements.txt incluye ambos:
- psycopg[binary]>=3.2.10,<4
- psycopg2-binary>=2.9.11,<3

Estas versiones mínimas admiten Python 3.14. El extra binary proporciona también
las bibliotecas nativas del controlador. Se conservan la conexión DATABASE_URL,
los comandos de arranque y los registros existentes; no hay cambios de tablas.

APLICACIÓN RÁPIDA SI YA TIENES LA VERSIÓN 17
1. Descomprime este ZIP.
2. Reemplaza requirements.txt en la raíz del repositorio que despliega Render.
   README.md también está actualizado con las instrucciones y la explicación.
3. Guarda los cambios en la rama usada por Render.
4. En el servicio de Render, confirma Build Command:
   pip install -r requirements.txt
5. Ejecuta Manual Deploy > Clear build cache & deploy.
6. Revisa el registro: deben instalarse psycopg y psycopg-binary y el despliegue
   debe terminar correctamente.

Mantén Start Command:
gunicorn app:app --workers 1 --threads 2 --timeout 300 --graceful-timeout 300

No subas el ZIP como sustituto de los archivos del programa: sube su contenido.
Esta entrega prepara la corrección; el despliegue de tu servicio queda pendiente
de subir los archivos y ejecutar los pasos anteriores.
